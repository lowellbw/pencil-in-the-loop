# Names that are not ours: the Swift standard library, Foundation, and the Apple
# frameworks this app uses. check_decls.py treats these as declared, and
# check_style.py exempts them from the British-spelling glossary — Apple's
# symbols keep Apple's spelling (STYLE.md § 2).
#
# Anything with one of these prefixes is allowed without an entry, so most SDK
# types need none: NS UI PK PDF CG CA CF CI CL CT AV SF SK MK WK UT OS QL XC
#
# ── HOW TO ADD TO THIS FILE ──────────────────────────────────────────────────
# Add an SDK name you used that is not here yet, in the section it belongs to.
# Never add one of ours: a project type that is declared nowhere is the bug this
# check exists to find.
#
# Three kinds of entry, and the narrowest one that works is the right one:
#
#   Widget                 a bare name, allowed anywhere in the repo
#   Schema.Version         allowed only as a member of that qualifier
#   #Preview               a macro, matched with its hash
#
# A bare entry is a hole in the undeclared-type check for that word everywhere,
# so single common words — `Type`, `Version`, `Preview`, `Predicate` — are
# qualified or hashed rather than listed bare. Those four were bare once, which
# meant a typo landing on any of them was accepted silently.
# ─────────────────────────────────────────────────────────────────────────────

# ── One build flag, here for the spelling check alone ────────────────────────
# `#if PENCILLOOP_STROKE_RECOGNIZER` is a compilation condition, not a type, and
# check_decls.py knows that — the name lives in that script's NON_TYPES. But
# check_style.py reads this same file for its British-spelling exemptions, and
# the flag is named after Apple's `PKStrokeRecognizer`, so it carries Apple's
# spelling and trips the glossary on the three `#if` lines that are real code.
# Renaming the flag is the tidier fix; it is spelled this way in docs/03 and
# CLAUDE.md, so the rename belongs with whoever changes those.
PENCILLOOP_STROKE_RECOGNIZER
