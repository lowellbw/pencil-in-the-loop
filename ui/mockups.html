Pencil-in-the-loop

A read-later inbox for long-form on iPad — papers, PDFs, agent output. Mark it up with the Pencil, talk your comments in, send the whole thing back to the conversation it came from.

Section 0 — Getting things in

One folder, four ways to fill it

This is the easy half, and it's what makes the app worth opening even when no agent is involved. Everything below writes to the same inbox/, so there is one ingest path to build, not five.

iOS share sheet
Share → Review
From Safari, Mail, arXiv, Files, anywhere. A share extension is about a day's work and covers most of what you'll actually send.
Cowork
Writes the file directly
A Cowork session already reaches your connected folders — it can drop a PDF straight into inbox/ with no new plumbing at all.
Claude Code
send_to_ipad()
Local MCP server, ~100 lines. Writes the same folder, records the session id.
You
Files / AirDrop
Drag anything in. Markdown is rendered to PDF on arrival; PDFs pass straight through.
📄 Research papers are the easy case — they're already PDFs, so ingest is a copy. Worth handling on arrival: pull title and authors for the library, and expect two-column academic layouts to stay page-view rather than reflow. This is the part that de-risks the whole idea — if it's a good offline paper reader first, you'll open it whether or not an agent sent you anything.

Section 2 — Can it go back to the same thread?

Yes — and there is a real mechanism for both Cowork and Claude Code

Five return paths. The app picks whichever applies to the doc's origin and tells you which one it used before you hit send, so context is never silently lost. Note that every one of them reads the same outbox/ folder — that's the whole reason one app serves Cowork, Claude Code and Codex without three integrations.

Cloud sessionClaude Code on the web
claude --cloud <session-id> -p "…" queues your review straight into a live web session. Works while the session is still running and while you're nowhere near the Mac — the best fit for reviewing from the sofa.
same thread
Idle local sessionthe CLI on your Mac
claude -p "…" --resume <session-id> restores the full conversation history, model and permissions. A file watcher fires it the moment your bundle lands, so the reply is waiting when you walk back to the desk.
same thread
Running local sessionyou're mid-turn at the keyboard
No external injection into a live local session — it has to be idle. In practice this barely bites: the app holds the bundle and fires the moment the session frees up, or you just type “read my review” yourself.
queued
Cowork threadwhere most of this will happen
Better than I first assumed. A Cowork session can create a poke-only scheduled task bound to itself, and firing that task delivers text into the session as an ordinary user turn — so your review lands in the same conversation. Needs account-level access to fire it, so realistically a small Mac-side helper does the firing.
same thread
Cowork, no helperzero new infrastructure
The session schedules a check-in that reads outbox/ when it next runs — or you open the thread and say “read my review.” Slightly manual, works today, nothing to build. Start here.
same thread

Section 3 — The screens

Design direction: it should look like Apple made it. System fonts, SF Symbols, system colours, standard containers. One accent colour, and the only other saturated colour in the app is the user's own ink. If a screen looks designed, it's wrong.

A library, not a viewer. Everything cached on device with full-text search across both the document text and your recognised handwriting — which is what makes it a thing you open on a plane rather than a utility you open once.

Section 4 — What's actually in the bundle

Three layers, sent together

Layer 1
Anchored comments
Voice and recognised handwriting, each tied to a quoted excerpt. Unambiguous, cheap, and the part Claude acts on directly.
Layer 2
Inked page images
Only pages with ink, cropped to the ink's bounding box plus context. An arrow pointing at a paragraph means something no text string preserves.
Layer 3
Closing prompt
The one free-text field: “now do X with all of this.” Turns a pile of notes into an instruction.
Mockups are illustrative, not pixel specs. Mechanisms shown are documented Claude Code behaviour (--resume, --cloud, session_id in hook payloads; poke-only scheduled tasks bound to a persistent Cowork session) and shipping Apple APIs (PencilKit, PKStrokeRecognizer in iPadOS 27, SpeechAnalyzer, PDFKit).
